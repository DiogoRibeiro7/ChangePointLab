# State-Space Methods: HMM, HSMM, and SD-HMM

State-space models assume observations are generated by hidden states following a Markov process.

## State-Space Modeling Principles
An HMM defines transition probabilities $P(z_t \mid z_{t-1})$ and emission distributions $p(x_t \mid z_t)$. Changepoints correspond to state transitions.

## Emission Models
- Gaussian, Poisson, or custom likelihoods describe how observations arise from states.
- Emission choice determines sensitivity to different types of shifts.

## Duration Modeling in HSMMs
Hidden semi-Markov models allow explicit duration distributions $P(d_t)$ so states can persist for specified lengths, reducing spurious rapid switching.

## SD-HMM for Compositional Data
Simplified Dirichlet HMMs model observations on the simplex. Dirichlet emissions with parameters $\alpha_k$ capture compositional changes.

## Convergence and Initialization
EM algorithms optimize model parameters; good initializations (e.g., from E-Divisive segments) improve stability.
